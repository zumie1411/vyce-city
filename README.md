> *Somewhere between the ocean, neon lights and 3AM, there's a city worth getting lost in.*

**VYCE//CITY** is an interactive cyberpunk-inspired digital city experience built around the atmosphere of neon-soaked streets, retro-futuristic architecture, underground culture and late-night driving.

Inspired by the aesthetic of Vice City, synthwave, retro futurism and open-world urban environments, VYCE//CITY is designed to feel less like a conventional website and more like a transmission from another city.

## `01` — THE CITY

VYCE//CITY isn't just a landing page. It's a fictional urban environment built with web technologies, designed around a dark visual identity, neon aesthetics and interactive elements.

From fictional districts to a street garage and hidden terminal, the website brings together elements of digital storytelling, UI experimentation and front-end development.

---

## `02` — FEATURES

| FEATURE | DESCRIPTION |
|---|---|
| ◈ Neon City Interface | A dark, cinematic visual design with neon accents, typography and atmospheric effects. |
| ◈ Fictional Districts | Explore different parts of the city, each with its own identity. |
| ◈ Street Garage | A collection of fictional cars with custom SVG illustrations and interactive effects. |
| ◈ Interactive City Map | A visual map experience with clickable district locations. |
| ◈ Hidden Terminal | An interactive terminal with commands accessible through a keyboard shortcut. |
| ◈ Glitch Effects | Visual distortions and signal interference-inspired animations. |
| ◈ Animated Traffic | A fictional street scene featuring moving vehicles. |
| ◈ Responsive Layout | Adapted for different screen sizes and devices. |

## `05` — THE TERMINAL

The city has a hidden terminal.

Press **`/`** to access the terminal and explore its commands.

```bash
help
whoami
districts
clear
exit
```

A little digital underground, hidden in plain sight.

## `07` — RUN LOCALLY

Want to explore the source code?

```bash
git clone https://github.com/zumie1411/vyce-city.git
```

Navigate to the project directory:

```bash
cd vyce-city
```

Open `index.html` in your browser or launch the project using VS Code Live Server.

---

## `08` — DEPLOYMENT

VYCE//CITY is deployed using Render as a static website and connected to GitHub for source control.

Every update can be pushed to the repository and redeployed.
