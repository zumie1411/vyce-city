# VYCE//CITY

An original cyberpunk-night city web experience for a static web-development challenge.

## Files
- `index.html` — semantic structure and page content
- `style.css` — visual styling, responsive layout, animation and CSS city artwork
- `script.js` — district interactions, city map modal, signal glitch and hidden terminal

## Run locally
Open the folder in VS Code and use Live Server, or open `index.html` directly in a browser.

## Deploy to GitHub Pages
1. Create a public repository (suggested: `vyce-city`).
2. Upload these three files at the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.

## Hidden feature
Press `/` to open the local terminal. Try `help`. Escape closes overlays.
